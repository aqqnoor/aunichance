## ETL (MVP): импорт данных о вузах и программах из CSV

Этот каталог содержит минимальный ETL‑скелет для загрузки университетов и программ в базу UniChance.

---

### 1. Источник данных

Для MVP предполагается ручная подготовка двух CSV‑файлов:

- `universities.csv` — список университетов;
- `programs.csv` — список программ.

Файлы могут быть собраны из открытых источников (официальные сайты вузов, открытые датасеты, рейтинги QS/THE), при этом:

- необходимо соблюдать условия использования источников;
- в репозитории **не** хранятся платные ключи и закрытые данные.

---

### 2. Формат CSV

#### 2.1 `universities.csv`

Ожидаемая структура (первая строка — заголовок):

```text
id,name,country_code,city,website,qs_rank,the_rank
```

- `id` — UUID университета (совпадает с `universities.id`);
- `name` — название университета;
- `country_code` — двухбуквенный код страны (ISO 3166‑1 alpha‑2, например `US`, `GB`, `DE`);
- `city` — город;
- `website` — основной сайт университета;
- `qs_rank` — позиция в QS (целое или пусто);
- `the_rank` — позиция в THE (целое или пусто).

#### 2.2 `programs.csv`

```text
id,university_id,title,degree_level,field,language,tuition_amount,tuition_currency,has_scholarship
```

- `id` — UUID программы (`programs.id`);
- `university_id` — UUID университета (`universities.id`);
- `title` — название программы;
- `degree_level` — уровень (значение типа ENUM `degree_level` или совместимая строка);
- `field` — направление подготовки (Computer Science, Economics и т.д.);
- `language` — язык обучения (например, `English`);
- `tuition_amount` — стоимость обучения в год (число или пусто);
- `tuition_currency` — валюта (`USD`, `EUR`, `KZT` и т.п., совместимо с ENUM `tuition_currency`);
- `has_scholarship` — `true` / `false`.

---

### 3. Запуск импорта

Команда:

```bash
cd etl
go run ./import_csv.go "$DATABASE_URL" ./universities.csv ./programs.csv
```

Где:

- `DATABASE_URL` — строка подключения к PostgreSQL;
- `./universities.csv` и `./programs.csv` — пути к подготовленным файлам.

Поведение:

- импорт выполняется в транзакции для каждой таблицы;
- используется `INSERT ... ON CONFLICT (id) DO UPDATE`, то есть импорт **идемпотентен** — повторный запуск обновляет существующие записи без дубликатов;
- поля `qs_rank` и `the_rank` приводятся к `INT`, пустые значения игнорируются.

---

### 4. План расширения ETL

В следующих итерациях ETL может быть расширен за счёт:

- подключения внешних API (QS, THE, официальные API вузов) с хранением метаданных в таблице `sources`;
- ведения истории запусков и статуса в таблице `fetch_log`;
- нормализации направлений обучения и языков (использование `languages` и дополнительных справочников);
- раздельных команд импорта для университетов, программ, дедлайнов, стипендий и статистики приёма.

Текущая реализация — минимальный рабочий скелет, который фиксирует договорённость “откуда берутся данные” и как их можно воспроизводимо загрузить в БД.
