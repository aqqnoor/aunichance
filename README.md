# UniChance

**UniChance** — интеллектуальный подбор вузов с оценкой шансов поступления для абитуриентов из стран СНГ, желающих поступить в университеты США и Европы.

## 🎯 Основные возможности

- **Быстрая оценка шансов** — мгновенный расчет вероятности поступления на основе ключевых показателей
- **Rule-based алгоритм** — прозрачная формула расчета, понятная пользователю
- **База университетов** — актуальная информация о требованиях и статистике приемов
- **Персональные рекомендации** — советы по улучшению профиля для повышения шансов
- **Детальный профиль** — возможность указать все данные для максимально точной оценки
- **Фильтрация и сортировка** — удобный поиск подходящих университетов

## 🚀 Быстрый старт

### Backend (Go + PostgreSQL)

1. Настройте переменные окружения:

```bash
export DATABASE_URL=postgres://user:password@localhost:5432/unichance?sslmode=disable
export JWT_SECRET=your-secret-key
```

2. Примените миграции (пример для psql, порядок по номеру файла):

```bash
cd backend-go/migrations
psql "$DATABASE_URL" -f 001_init.sql
psql "$DATABASE_URL" -f 002_profile_and_scores.sql
psql "$DATABASE_URL" -f 003_updated_at_and_search_vector.sql
psql "$DATABASE_URL" -f 004_sources_links_fetchlog.sql
psql "$DATABASE_URL" -f 005_smart_matching.sql
psql "$DATABASE_URL" -f 010_drop_shortlists.sql
psql "$DATABASE_URL" -f 011_search_vector_fix.sql
psql "$DATABASE_URL" -f 012_degree_level_enum.sql
psql "$DATABASE_URL" -f 013_languages.sql
psql "$DATABASE_URL" -f 014_indexes.sql
```

3. Запустите backend‑API:

```bash
cd backend-go/cmd/api
go run .
```

API будет доступен по адресу `http://localhost:8080` (порт настраивается через `PORT`).

### Frontend

```bash
npm install
npm run dev
```

Приложение будет доступно по адресу `http://localhost:5173`

### Сборка фронтенда для продакшена

```bash
npm run build
```

## 📱 Основные экраны

### 1. Главная страница
Быстрая оценка на основе минимального набора данных:
- Средний балл (GPA)
- Уровень английского (IELTS/TOEFL)
- Основные достижения
- Желаемый регион обучения

### 2. Страница результатов
Список подходящих университетов с:
- Процентом шанса поступления
- Категоризацией (Reach/Target/Safety)
- Детальной информацией о требованиях
- Персональными рекомендациями

### 3. Профиль абитуриента
Детальное заполнение данных:
- Академические показатели (GPA, тесты)
- Внеклассные достижения
- Предпочтения по странам и направлениям
- Дополнительная информация

## 🧮 Алгоритм расчета

UniChance использует rule-based формулу, которая учитывает:

- **GPA (40% веса)** — сравнение с минимальными и средними требованиями
- **Языковые тесты (25% веса)** — IELTS/TOEFL результаты
- **Стандартизированные тесты (15% веса)** — SAT, ACT, GRE, GMAT
- **Достижения (10% веса)** — олимпиады, спорт, волонтерство, лидерство
- **Уровень конкуренции (10% веса)** — корректировка на основе процента приема

Алгоритм готов к интеграции ML-модели в будущем.
